## Agent skills

### Issue tracker

Issues live in GitHub Issues on `kdj309/scanbite` (`gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical roles use the same strings in the tracker: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: root `CONTEXT-MAP.md` points at per-package `CONTEXT.md` files; system-wide ADRs live in `docs/adr/`. See `docs/agents/domain.md`.
